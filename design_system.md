# PocketTogether Design System & Brand Identity
**Version 1.0**

## 1. Brand Essence

**PocketTogether** is not just an expense tracker; it is a collaborative financial wellness platform. It is designed to feel intimate, premium, and calm.

*   **Core Philosophy**: "Financial Clarity through Native Elegance."
*   **Tone of Voice**: Encouraging, Precise, Premium, and Private. We don't yell; we guide.
*   **Visual Metaphor**: "The Cockpit." Dark, focused, with glowing instruments (gradients) providing critical data at a glance.

---

## 2. Color Palette

Our palette is built on "Deep Space" foundations with "Nebula" accents. We avoid flat solid colors in favor of deep blacks and vibrant gradients.

### 2.1. Foundations (Backgrounds)
| Token | Hex / Value | Usage |
| :--- | :--- | :--- |
| `bg-primary` | `#000000` | The infinite background. Used for all main page bodies. |
| `bg-surface` | `#1c1c1e` | The physical card material. Used for widgets, lists, and modals. |
| `border-subtle`| `white/5` | The delicate edge lighting on glass components. |

### 2.2. Brand Gradients
Used for primary actions, logos, and high-emphasis data.

*   **Primary Brand**: `bg-gradient-to-br from-blue-500 to-purple-600`
*   **Secondary Brand**: `bg-gradient-to-r from-cyan-500 to-blue-500`

### 2.3. Semantic Colors
Colors that convey meaning. We use the 400-500 scale for text/icons to ensure readability against dark backgrounds.

*   **Success (Income/Safe)**: `text-green-400` / `bg-green-500/20`
*   **Danger (Expense/Debt)**: `text-red-400` / `bg-red-500/20`
*   **Warning (Limits)**: `text-orange-400` / `bg-orange-500/20`
*   **Info (Insights)**: `text-blue-400` / `bg-blue-500/20`

## 3. Typography

We rely on the native system font stack to ensure the app feels at home on any device (Apple’s San Francisco on iOS, Roboto on Android).

*   **Family**: `font-sans` (Inter/System Default)
*   **Headings**: `font-bold`, tight tracking.
*   **Data**: `font-mono` is used strictly for currency and numbers to ensure alignment.

### Hierarchy
*   **Display**: `text-3xl font-bold` (Page Titles)
*   **Heading**: `text-lg font-bold` (Widget Titles)
*   **Body**: `text-sm text-gray-300` (Content)
*   **Caption**: `text-xs text-gray-500 uppercase font-bold tracking-wider` (Labels)

---

## 4. UI Components & Glassmorphism

Our defining aesthetic is **"Dark Glass."**

### 4.1. The "Glass Card"
Every widget or container follows this rule:
```tsx
className="bg-[#1c1c1e]/80 backdrop-blur-xl border border-white/5 rounded-3xl"
```
*   **Roundedness**: Always `rounded-3xl` for large containers, `rounded-2xl` for inner items.
*   **Backdrop**: `backdrop-blur-xl` ensures the background content bleeds through subtly.
*   **Glow**: Use `shadow-2xl` or internal gradients to create depth.

### 4.2. Navigation
*   **Mobile**: Bottom floating "Island" bar. `bg-gray-900/95 backdrop-blur-2xl`.
*   **Desktop**: Left vertical sidebar or Top sticky bar.
*   **Headers**: 
    *   **NativeHeader**: The standard for all pages. Contains Avatar + Greeting/Title + Notification Bell.
    *   *No Double Headers*: If a page has a generic top bar, it must be hidden on mobile in favor of the NativeHeader.

### 4.3. Lists
*   **Inset Grouped**: On mobile, simple lists (like Settings) should look like iOS Inset Grouped lists.
    *   `bg-[#1c1c1e] rounded-3xl` container.
    *   Items separated by `border-b border-white/5`.
    *   Last item has no border.

## 5. Motion & Interaction

Motion is not decoration; it is feedback.

*   **Page Transitions**: Elements should `fadeInUp` (fade in and slide up 20px).
*   **Staggering**: Lists should load with `staggerContainer` to prevent "wall of text" loading.
*   **Active State**: All interactive cards must scale down slightly on press (`active:scale-[0.98]`).
*   **Library**: `framer-motion`.

## 6. Iconography

*   **Set**: `lucide-react`
*   **Stroke Width**: Standard is `2px`.
*   **Sizing**: 
    *   `w-5 h-5` for standard actions.
    *   `w-4 h-4` for tight spaces/metadata.
